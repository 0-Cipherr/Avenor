# Avenor Contracts

**Avenor** is a modular on-chain yield infrastructure designed to connect vaults, strategies, and cross-chain bridges.

### 🏗️ Architecture

* **Vaults** — ERC-4626 yield vaults
* **Strategies** — Modular yield strategies
* **Registry** — Tracks deployed components
* **Factory** — Deploys vaults and strategies
* **Bridges** — Cross-chain asset & message routing

### ⚙️ Stack

* Solidity
* Foundry
* OpenZeppelin
* LayerZero
